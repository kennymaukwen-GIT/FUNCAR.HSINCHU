  • 「C180 COUPE AMG」不是 AMG 車款。它通常指加了 AMG Line 運動化外觀的 C 180 Coupé，動力仍是 156 匹四缸引擎、後輪驅動；真正的 AMG 版本是 Mercedes-AMG C 43 4MATIC（V6 雙渦輪、四驅）與 C 63。
  • 2018 年小改款換上新設計的 LED 頭燈與尾燈、調整前後保桿，可選 Multibeam LED 頭燈與 12.3 吋數位儀表。2021 年式 C 180 Coupé 屬於小改款。

C-Class Coupé（C205）的定位

C205 是第四代 C-Class（W205）的雙門 Coupé 版本，和四門房車共用後輪驅動平台，2015 年 9 月在法蘭克福車展首發，生產到 2023 年。它是賓士入門的雙門四座車款，比 E-Class Coupé 小一級，與 BMW 4 Series、Audi A5 同級。

2021 年新一代 C-Class（W206）在台灣上市時只有房車與旅行車，沒有 Coupé 版本。賓士在 2023 年 7 月發表 CLE，用一個車系同時取代 C-Class 與 E-Class 的 Coupé 和敞篷車。所以 C205 是最後一代名稱叫「C-Class Coupé」的車。

台灣常見的版本是 C 180 Coupé、C 300 Coupé 和 Mercedes-AMG C 43 4MATIC Coupé。很多 C 180 Coupé 會掛著「AMG」字樣販售，下面會先說清楚「AMG Line」和真正的 AMG 車款差在哪。

「C180 COUPE AMG」是什麼？AMG Line 和 AMG 車款的差別

賓士的 AMG Line 是一般車型的運動化外觀與配備套件，台灣常稱為「AMG 跑車化套件」。它改的是外觀、輪圈與部分底盤配備，引擎動力不變。所以「C180 COUPE AMG」通常指的是加了 AMG Line 外觀的 C 180 Coupé，動力仍是 C 180 的四缸引擎。

真正的 AMG 車款，原廠車名前面會是「Mercedes-AMG」，例如 Mercedes-AMG C 43 4MATIC Coupé、Mercedes-AMG C 63 Coupé，引擎、傳動與底盤都和一般 C-Class 不同。

台灣總代理在 2016 年上市時就有「C 250 Coupé AMG Line」這個車型名稱；2018 年小改款上市時，台灣媒體報導 C 180 Coupé 的 AMG 跑車化外觀套件是選配。一台 C 180 Coupé 有沒有 AMG Line、裝了哪些項目，要以該車的配備與鑑定為準。

前期與小改款怎麼分、規格對照

C205 Coupé 以 2018 年小改款為分界。分辨重點：

  • 頭燈與尾燈：小改款換上重新設計的 LED 頭燈與尾燈，並可選 Multibeam LED 頭燈。
  • 前後保桿：小改款的前後保桿造型調整，但變化不大，最好和尾燈一起看。
  • 儀表：小改款可選 12.3 吋全數位儀表；台灣 2018 年試駕車的數位儀表與 10.25 吋螢幕是加價選配，所以沒有數位儀表不代表是前期車。
  • 最準的方法：看行照、車身號碼對應的出廠日期與引擎型式。2021 年式 C 180 Coupé 一定是小改款。

車源怎麼選：台灣總代理、日本、韓國與國內二手車

  • 台灣總代理車：可以查國內保養紀錄，配備依台灣賓士當年的車型編成，例如小改款 Coupé 沒有 C 200。總代理歷年新車價也是比價的參考。
  • 日本車源：可以對照日本拍賣評分表了解車況，並用車身號碼確認出廠日期、引擎型式與配備。
  • 韓國車源：同樣以車身號碼確認年份、引擎與配備，看車時以實車配備為準。
  • 國內二手車：重點看保養紀錄是否完整、是否按時保養。

各市場的車型名稱與配備組合不同，同樣叫 C 180 Coupé，AMG Line 的內容也可能不一樣，看車時以實車配備為準。

看車時的檢查重點

以下是維修廠、零件商常提到的檢查項目與召回查詢方式，不是每台車都會發生，看車時逐項確認即可：

  1. 召回是否完成：台灣賓士曾針對 C-Class 發布頭燈照射角度相關的召回。購買前請以車身號碼向原廠或總代理查詢是否有未完成的召回。
  2. 冷車發動聲音：維修資料常提到 M274 等四缸引擎的正時鏈條問題，冷車發動時聽有沒有短暫的鏈條異音，並看保養紀錄是否按時更換正確規格的機油。
  3. 凸輪軸調整器附近滲油：零件商的 W205 指南把凸輪軸調整器電磁閥滲油列為常見項目，看引擎上方前側有沒有油漬。
  4. 9 速自排：試車時注意低速換檔是否平順、有沒有頓挫。
  5. 燈具與電子配備：小改款的 LED 或 Multibeam 頭燈、數位儀表與中控螢幕都要實際操作，確認功能正常、沒有警示燈。
  6. 輪圈與輪胎：AMG Line 常配大尺寸鋁圈與低扁平比輪胎，看輪圈有沒有刮傷變形、輪胎磨耗是否平均。
  7. 車況文件：日本車源可對照日本拍賣評分表，在台車看保養紀錄。貿鑫每台車都由 Goo 官方鑑定專員在店實車鑑定。

常見問題

C180 Coupé AMG 是 AMG 嗎？

不是。「C180 COUPE AMG」通常指加了 AMG Line 運動化外觀套件的 C 180 Coupé，改的是保桿、水箱罩、輪圈等外觀配備，引擎仍是 156 匹的四缸渦輪、後輪驅動。真正的 AMG 版本原廠車名是 Mercedes-AMG C 43 4MATIC Coupé 或 Mercedes-AMG C 63 Coupé。

C-Class Coupé 前期和小改款怎麼分？

小改款在 2018 年發表，換上重新設計的 LED 頭燈與尾燈，前後保桿也有調整，並可選 Multibeam LED 頭燈與 12.3 吋數位儀表。保桿變化不大，最準的方法是看行照與車身號碼對應的出廠日期。2019 年以後出廠的 C205 都是小改款。

C 180 Coupé 是 1.6 升還是 1.5 升？有 EQ Boost 嗎？

前期與小改款初期的 C 180 Coupé 是 1.6 升渦輪，約 2019 年起改為 1.5 升 M264 渦輪，兩者都是 156 匹、250 牛頓米。台灣 2018 年試駕報導指出 EQ Boost 只用在 C 200，台灣 2022 年式 C 180 Coupé 規格表也沒有列出 48V 輕油電系統。

C 180、C 300、AMG C 43 Coupé 差多少？

小改款歐規與台灣的馬力分別是 C 180 156 匹、C 300 258 匹、Mercedes-AMG C 43 4MATIC 390 匹。C 180 與 C 300 是後輪驅動的四缸車，AMG C 43 是 3.0 升 V6 雙渦輪加 4MATIC 四驅，0–100 km/h 4.7 秒。

C-Class Coupé 停產了嗎？後繼車是什麼？

C205 Coupé 在 2023 年停產，新一代 W206 C-Class 沒有 Coupé。賓士在 2023 年 7 月 5 日發表 CLE，取代 C-Class 與 E-Class 的 Coupé 和敞篷車。台灣 2024 年 3 月上市，CLE 200 Coupé 售價 288 萬元起。

C-Class Coupé 在台灣的新車價是多少？

台灣總代理 2016 年 C 180 Coupé 售價 203 萬元起；2018 年小改款 C 180 Coupé 205 萬元、C 300 Coupé 279 萬元、AMG C 43 4MATIC Coupé 364 萬元；2020 年式 C 180 Coupé 進化版 215 萬元；2022 年式 226 萬元。中古車與外匯車價格依年份、里程、車況而定。
